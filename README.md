# 产品工作流 Skills

面向产品经理的技能集合，覆盖会议纪要、竞品分析、需求挖掘、PRD 编写、原型制作、数据分析、AI 资讯和工作复盘。点击技能名称即可打开对应的 `SKILL.md`，查看适用场景和执行步骤。

| 模块 | 技能 | 输入与产出 |
| --- | --- | --- |
| 会议纪要 (meetingMinutes) | [会议纪要生成](./meetingMinutes/skill/SKILL.md) | 将会议转写稿整理为 Markdown 纪要，提取讨论要点、决策和行动项。 |
| 竞品逆向 (competitorAnalysis) | [产品逆向分析](./competitorAnalysis/skill/SKILL.md) | 根据产品截图识别核心功能和使用场景，推导业务流程、技术架构与设计思路。 |
| 需求清洗 (productReverseAnalysis) | [产品需求挖掘](./productReverseAnalysis/skill/SKILL.md) | 清洗、分类和聚类 CSV 评论，提取迭代需求并生成带优先级的产品路线图。 |
| 文档工厂 (prd) | [PRD 生成](./prd/skill/SKILL.md) | 通过多轮澄清补齐业务逻辑和边界条件，将初步想法整理为可执行的 PRD。 |
| 原型演示 (prototypeDemo) | [产品原型设计](./prototypeDemo/skill/product-prototype-design/SKILL.md) | 根据产品想法或 PRD 生成独立的高保真 HTML 交互原型，可在浏览器中直接预览。 |
| 原型演示 (prototypeDemo) | [PinMe 静态部署](./prototypeDemo/skill/pinme-deploy/SKILL.md) | 将静态页面或前端构建产物发布到 IPFS，生成可分享的访问链接。 |
| 数据分析 (dataAnalysis) | [CSV 数据分析](./dataAnalysis/skill/SKILL.md) | 从数据探索、清洗到指标分析，按需输出 Markdown 报告、交互式 HTML 或仪表板。 |
| 情报雷达 (aiNews) | [AI 资讯获取与展示](./aiNews/skill/SKILL.md) | 汇总 AIBase、36 氪 AI 频道等来源的动态，生成 HTML 资讯展示页。 |
| 进化管家 (EvolutionManager) | [Skill Evolver](./EvolutionManager/skills/skill-evolver/SKILL.md) | 从多轮对话和用户反馈中提炼可复用约束，生成优化版 Skill。 |
| 进化管家 (EvolutionManager) | [周报生成器](./EvolutionManager/skills/weekly-report/SKILL.md) | 将零散工作记录、关键词或纪要片段整理为结构化纯文本周报。 |

## 使用方式

打开所需技能的说明，将对应材料交给支持 Skills 的助手，例如会议转写稿、产品截图、评论 CSV 或 PRD。模板、参考资料和脚本的用法见各技能页面。
